Nutrideel

Calorie & nutrition tracker · React Native / Expo

An offline-first nutrition tracker with meal, weight, activity, and fasting logging, SVG progress charts, and a thermodynamic weight-forecasting engine. Describe what you ate in plain language and Gemini breaks it into calories and macros — with a fully offline heuristic fallback, so core features work with no network and no API key at all.

On-device persistence via AsyncStorage, unit conversion, local reminder notifications, and haptic-driven UI feedback throughout. Configured for Android distribution via EAS Build. MIT licensed and live on GitHub.

React Native Expo Gemini API AsyncStorage TypeScript
WHY I BUILT IT

I wanted a nutrition tracker that actually fit how I eat, and I wanted a real reason to learn mobile development instead of another tutorial. This was both at once.

Aromatic Aura

Recipe discovery & meal planning · React Native / Expo

A 4-screen recipe discovery app with a custom "Cosmic Obsidian" theme — deep blacks, saffron accents, and a layout built to stay legible with wet hands and a phone propped up mid-cook.

Pulls live recipe, ingredient, and image data from TheMealDB API with client-side caching to keep browsing fast and offline-tolerant. Save favorites to a private collection, auto-generate a grocery checklist from a recipe's ingredients, with persistent state via Zustand. Shipped as a real installable Android APK through EAS Build.

React Native Expo TheMealDB API Android APK TypeScript
WHY I BUILT IT

I wanted to go past "app that runs in Expo Go" and actually ship something installable — figuring out EAS Build and a real signed APK taught me as much as the app itself did.
